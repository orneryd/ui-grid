Theming

Theme System

UI Grid renders inside Shadow DOM. All visual customization flows through CSS custom properties that pierce the shadow boundary, plus ::part() selectors for structural overrides. Toggle the theme controls in the nav bar to see the grid adapt in real time.

Host Attribute Pattern

The demo app uses data-color-mode and data-visual-mode attributes on the root component to drive a 2x2 theme matrix. Each combination defines a full set of semantic CSS tokens that cascade into the grid:

You can use this same pattern in your own app to support multiple themes without JavaScript theme-switching logic — just set a data attribute and let CSS do the work.
