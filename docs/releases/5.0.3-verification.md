## Scope and limitations

WASM is intentionally opt-in; users relying on automatic loading must follow the documented opt-in API. #7399's initial right-pin scroll report did not reproduce in the checked Chrome configuration (`scrollLeft` was zero), so this release does not claim a general fix for that report. Per-grid component overrides remain outside this release; page-wide override contracts are documented.

OpenSpec proposal/task files were maintained. The OpenSpec CLI was unavailable, so its schema validator was not run. The repository has no applicable `make verify` target; npm build, test and package commands are the verification interface.

Tagging, publication to npm and cutting the GitHub release remain maintainer actions after the release PR is merged.
